현재 경기도의 한 외국어고등학교에 재학 중인 학생입니다. 창작과 언어, 개발 등 후술할 여러 분야에 관심을 두고 활동하고 있습니다.

본명은 송지후이며, 영어로는 Owen(오웬), 일본어로는 和泉流希(이즈미 루키)라는 이름을 사용하고 있습니다. 한편 유천(流泉)이라는 호도 사용하고 있습니다.

한편 온라인에서 부르실 때는 닉네임 ‘쩌모’나 ‘삼쩌모’라고 부르시면 됩니다!

관심을 두는 것

언어학 / 도시학 / 사회학 / 수학 / 지구과학 ...

‘넓고 깊게’를 추구합니다. 새로운 분야를 접하는 것도 좋아하고, 한 번 관심을 가진 것은 가능한 한 깊이 이해해 보고 싶어 해 배우는 과정 자체를 즐기는 편입니다.

학문적으로는 문리과, 사회, 공학에 걸쳐 여러 분야에 관심이 있습니다만 아직은 아주 많은 지식을 가지고 있는 것은 아닙니다.

창작 / 프로그래밍 / 디자인 / 사진 / 그림 / 만년필 / 마작 ...

한편 여러 취미가 있습니다. 오래 갈 취미는 아주 오래 가고, 금방 사라질 취미는 며칠도 안 가는 편이라, 이곳에는 꽤나 오래 가고 있는 취미를 적어두었습니다.
