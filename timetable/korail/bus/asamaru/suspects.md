# 고속버스 노선표: 확인할 것

정류장 차례·경유 여부는 TAGO 구간별 시각을 맞물려 짐작한 것. 아래는 근거가 약하거나 따로 확인되지 않은 것.

## 1. 반대 방향·구간 소요로 확인되지 않은 연결 (시각만 맞물림)

- 김제 → 익산팔봉 (40분 뒤) … 센트럴시티(서울) 행, 6번 맞물림
- 부안 → 서천 (50분 뒤) … 인천공항T1 행, 3번 맞물림
- 부안 → 서천 (50분 뒤) … 인천공항T2 행, 3번 맞물림
- 익산 → 익산팔봉 (15분 뒤) … 센트럴시티(서울) 행, 6번 맞물림

## 2. 맞물린 횟수가 적은 연결 (3번 이하)

- 부안 → 서천 (50분 뒤) … 인천공항T1 행, 3번
- 부안 → 서천 (50분 뒤) … 인천공항T2 행, 3번
- 부안 발 인천공항T2 행이 인천공항T1 에 들름, 3번
- 서천 발 인천공항T2 행이 인천공항T1 에 들름, 3번

## 3. 정류장 차례가 방향마다 어긋나는 표 (TAGO 소요가 뒤바뀐 듯)

- 용인 → 용인기흥역 → 용인신갈 → 내서 → 마산 → 창원 / 반대: 창원 → 내서 → 마산 → 용인신갈 → 용인기흥역 → 용인
